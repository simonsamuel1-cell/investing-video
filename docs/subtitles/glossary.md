## Never translate (keep exactly)
Tuntun, Tuntun Sekuritas, Orang Tuntun, Chart Pro, Pro (the button), TradingView, IHSG, IDX, stock tickers (BBCA, BBRI,

## Numbers
Indonesian decimals use a comma: "26,7 juta" = 26.7 million → EN "26.7 million", ZH "2670万", JA "2,670万", KO "2,670만".
"Rp9.000" = 9,000 rupiah → EN "Rp9,000", ZH/JA/KO keep "Rp9,000". Percentages unchanged.

Rules settled in this pass:
- Candle colours: EN keeps green/red. ZH/JA/KO never use a colour word to say a candle's direction (red = UP in those markets); use 阳线/阴线, 陽線/陰線, 양봉/음봉. Exceptions kept on purpose: established pattern names (红三兵 / 赤三兵 / 적삼병), and TA09 rows 147–151, which talk about the on-screen colour of the volume bars themselves.
- Bracketed long forms (JA 相場構造（マーケットストラクチャー）, 横ばい（レンジ）, 確認（コンファメーション）, 日中足（イントラデイ）; ZH 移动平均线（均线）): long form at the first mention in each video, short form after. The CTA clip counts as its own video. For konfirmasi, the first mention is the first noun "konfirmasi"; the verb "mengonfirmasi" is just 確認する.
- JA always uses インジケーター for indikator (never 指標).
- KO: 이탈 ends in a consonant, so it takes 을/은 (하향 이탈을, 하향 이탈은).
- Numbers: thousands with commas (20,350; 1,750). ZH 万 amounts follow the existing Numbers rule (1000万, 2670万); JA/KO use a comma (1,000万, 1,000만).
