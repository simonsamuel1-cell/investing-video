# Value Investing — Video 01: Apa Itu Value Investing

Proyek Remotion episode Tuntun Academy — komposisi utama `ApaItuValueInvesting` (60 fps).

## Menjalankan

```console
npm i
npm run dev      # Remotion Studio di port 3021
npm run render   # render ke out/
```

## Yang tidak ikut di repo

- `node_modules/` dan `out/` (hasil render & QA).
- **Semua file `.wav`** — VO dan audio kerja berukuran 84–122 MB per file, melebihi batas 100 MB GitHub.
  Salin dari folder episode (`01_VO/`) atau disk kerja ke `public/vo/` sebelum membuka Studio.
  File yang dirujuk kode:

- `public/vo/vi01_vo.wav`
- `public/vo/vi01_vo_v4.wav`
