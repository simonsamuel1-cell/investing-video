# Investing 101 — Video 05: Jalur Bertumbuh

Proyek Remotion episode Tuntun Academy — komposisi utama `JalurInvestor` (60 fps).

## Menjalankan

```console
npm i
npm run dev      # Remotion Studio di port 3019
npm run render   # render ke out/
```

## Yang tidak ikut di repo

- `node_modules/` dan `out/` (hasil render & QA).
- **Semua file `.wav`** — VO dan audio kerja berukuran 84–122 MB per file, melebihi batas 100 MB GitHub.
  Salin dari folder episode (`01_VO/`) atau disk kerja ke `public/vo/` sebelum membuka Studio.
  File yang dirujuk kode:

- `public/vo/ide-v5/${scene}.wav`
- `public/vo/inv05_vo_v2_outro29149.wav`
- `public/vo/inv05_vo_v3_isi.wav`
- `public/vo/inv05_vo_v5_isi.wav`
- `public/vo/inv05_vo_v5_outro29140.wav`
